# 宠知AI 平台功能扩展规格说明

## 1. 问题与背景

当前宠知AI 平台已实现用户认证、宠物图像识别、品种科普、资讯管理、宠物档案、AI 对话助手、管理员后台等核心模块。对照《宠物服务平台设计要求》，仍缺失以下业务能力：

- 宠物用品商城与订单管理（无商品、无购物车、无订单流转）
- 领养与寄养信息管理（无信息发布、无申请审核流程）
- 社区交流与评论管理（仅有 AI 对话，无用户发帖/评论/点赞互动）
- 商家角色（需求中三类角色之一，本次暂不实现，商城商品由管理员发布）

本次扩展旨在补齐上述四个业务模块，使平台功能覆盖需求文档要求的全部核心模块。

## 2. 用户与目标

### 2.1 用户角色

| 角色 | 说明 |
|---|---|
| 普通用户 | 浏览商城、下单、发布领养寄养信息、申请领养寄养、发帖评论点赞、管理自己的订单/帖子/领养信息 |
| 管理员 | 发布管理商品、管理订单（发货）、审核/下架领养寄养信息、管理社区帖子与评论 |

> 注：需求中的"商家"角色本次暂不实现，商品发布与订单管理由管理员代为执行。

### 2.2 目标

- 提供完整的宠物用品在线购买流程（商品浏览 → 购物车 → 下单 → 支付 → 发货 → 完成）
- 提供领养与寄养信息发布、浏览、申请、审核的完整闭环
- 提供用户社区交流能力（发帖、评论、点赞）
- 所有新模块均纳入管理员后台统一管理
- 保持现有代码风格、响应格式（Result<T>）、鉴权机制（JWT + 双拦截器）一致

### 2.3 非目标

- 不实现真实支付对接，支付操作为模拟（点击支付即状态变更）
- 不实现商家角色独立登录与商家后台
- 不实现物流追踪
- 不实现搜索功能（列表筛选仅限分类/状态）

## 3. 功能需求

### 3.1 宠物用品商城与订单

**FR-1 商品浏览**
- 前台商品列表页，支持按分类筛选、分页
- 商品详情页展示名称、价格、库存、图片、描述
- 仅上架（status=1）商品对前台可见

**FR-2 购物车**
- 登录用户可将商品加入购物车、修改数量、移除
- 购物车列表显示商品信息、数量、小计、合计
- 选中部分商品结算

**FR-3 下单与支付**
- 从购物车或商品详情页（立即购买）创建订单
- 订单包含收件人姓名、电话、地址
- 订单状态流转：待付款 → 已付款 → 已发货 → 已完成 / 已取消
- 支付为模拟操作（点击支付即变为已付款）
- 用户可取消待付款订单

**FR-4 我的订单**
- 按状态筛选（全部/待付款/已付款/已发货/已完成/已取消）
- 订单详情查看
- 已发货订单可确认收货

**FR-5 管理员商品管理**
- 商品增删改查、上下架
- 商品字段：名称、描述、价格、库存、封面图、轮播图、分类、状态

**FR-6 管理员订单管理**
- 订单列表（按状态筛选）、订单详情
- 已付款订单可发货
- 可修改订单状态

### 3.2 领养与寄养

**FR-7 信息发布与浏览**
- 登录用户可发布领养或寄养信息
- 信息字段：类型（领养/寄养）、宠物名称、品种、类型（猫/狗）、年龄、性别、照片、描述、联系方式
- 前台列表页，支持按类型筛选、分页，仅展示已审核通过的信息

**FR-8 申请与审核**
- 登录用户可对领养寄养信息提交申请（附留言和联系方式）
- 信息发布者可查看申请列表，审核通过/拒绝
- 每个用户对同一条信息只能提交一次申请

**FR-9 我的领养寄养**
- 我发布的信息列表，可编辑、删除、查看申请
- 我申请的信息列表，查看审核状态

**FR-10 管理员管理**
- 领养寄养信息列表、审核通过/拒绝、下架、删除
- 申请列表查看

### 3.3 社区交流与评论

**FR-11 发帖与浏览**
- 登录用户可发布帖子（标题、正文、封面图、分类）
- 帖子列表页，支持按分类筛选、分页
- 帖子详情页展示正文、作者、点赞数、评论数

**FR-12 评论与点赞**
- 登录用户可对帖子发表评论
- 支持回复评论（二级评论）
- 登录用户可点赞/取消点赞帖子
- 点赞数实时更新

**FR-13 我的社区**
- 我发布的帖子列表，可编辑、删除

**FR-14 管理员管理**
- 帖子列表、删除帖子
- 评论列表、删除评论

## 4. 非功能需求

- **NFR-1 一致性**：所有新增接口遵循 Result<T> 统一响应格式、ErrorCode 错误码、GlobalExceptionHandler 全局异常处理
- **NFR-2 鉴权**：前台需登录接口走 JwtInterceptor；管理员接口走 AdminInterceptor；公开列表接口（商品列表、领养寄养列表、社区帖子列表）免登录
- **NFR-3 分页**：列表接口统一使用 PageResult<T>，默认 page=1, size=10，最大 size=50
- **NFR-4 数据安全**：用户只能修改/删除自己的数据；管理员可操作全部
- **NFR-5 前端风格**：新页面遵循现有 hifi-vue-restore 风格，全屏布局 + clamp 自适应边距
- **NFR-6 数据库**：新增表使用 utf8mb4，遵循现有字段命名规范（snake_case），create_time/update_time 自动维护

## 5. 约束与依赖

- **技术栈约束**：后端 SpringBoot 3.2.12 + JDK 21 + MyBatis-Plus 3.5.5 + MySQL 8；前端 Vite 5 + Vue3 + Element Plus + Pinia
- **鉴权依赖**：复用现有 JwtUtil、UserContext（ThreadLocal）、JwtInterceptor、AdminInterceptor
- **文件上传依赖**：复用现有 FileUploadUtil，图片上传接口 /recognition/upload 或新增通用上传
- **前端请求依赖**：复用现有 request.js（axios 封装，自动携带 token）
- **图片资源**：商品/领养寄养/帖子封面图可使用 AI 配图或占位图，遵循"演示兜底+真实 API 渐进增强"模式

## 6. 验收标准

### 规则类（rule）

| 编号 | 验收标准 |
|---|---|
| AC-1 | 数据库新增 9 张表（adoption, adoption_application, post, comment, post_like, product, cart, `order`, order_item），字段设计合理，有必要索引 |
| AC-2 | init.sql 包含全部新表的 DDL 和初始演示数据 |
| AC-3 | 商城：商品列表/详情、购物车增删改查、下单、支付（模拟）、取消、确认收货接口全部可用 |
| AC-4 | 商城：管理员商品增删改查、上下架接口可用；管理员订单列表/发货接口可用 |
| AC-5 | 领养寄养：发布、列表、详情、申请、审核、我发布的、我申请的接口可用 |
| AC-6 | 领养寄养：管理员审核/下架/删除接口可用 |
| AC-7 | 社区：发帖、列表、详情、评论、点赞/取消、我发的帖子接口可用 |
| AC-8 | 社区：管理员删除帖子/评论接口可用 |
| AC-9 | 前端新增路由全部可访问，页面无白屏、无控制台报错 |
| AC-10 | 前端导航栏新增"领养寄养""社区""商城"入口 |
| AC-11 | 所有需登录接口未登录时返回 401，管理员接口非管理员返回 403 |
| AC-12 | 用户只能修改/删除自己的领养寄养信息、帖子、评论 |
| AC-13 | 后端 `mvn compile` 通过，前端 `vite build` 通过 |

### 评估类（rubric）

| 编号 | 维度 | 评分标准 | 阈值 |
|---|---|---|---|
| AC-14 | 功能完整度 | 0=缺失核心流程；1=主流程可用但有边角缺失；2=四个模块主流程+管理端全覆盖 | ≥2 |
| AC-15 | 代码一致性 | 0=风格混乱；1=基本遵循现有规范；2=完全遵循 Result/PageResult/ErrorCode/拦截器/命名规范 | ≥1 |
| AC-16 | 前端 UI 质量 | 0=页面丑陋/错乱；1=可用但风格不统一；2=与现有页面风格统一，布局自适应无裂图 | ≥1 |
